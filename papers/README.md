# papers/ - 里程碑論文精華筆記存放區

本資料夾用於存放從 `raw/` 原始 PDF 所提煉的結構化論文摘要與分析筆記。

## 命名規範：
- 格式：`<年份>-<第一作者姓氏>-<模型或主題簡稱>.md`
- 範例：`2018-chen-crnn-ser.md`

## 內文規範：
- 標題與基本元數據（Title, Authors, Venue, Year, arXiv/DOI 連結）
- 問題背景與核心動機
- 模型架構與張量維度流（附架構圖文字或 ASCII/Mermaid 說明）
- 關鍵數學公式（LaTeX 推導）
- 實驗設定與評測結果（明確註記評測協議 LOSO / 10-Fold、WA/UA 數值）
- 局限性與觀點對比
